# מבחן ביצועי משימות

פרויקט Full Stack פשוט הכולל ASP.NET Core Web API, צד לקוח סטטי ב-HTML/CSS/JavaScript, ובסיס נתונים SQLite עם Entity Framework Core.

## יכולות

- יצירה אוטומטית של בסיס הנתונים בעת עליית השרת.
- יצירה אוטומטית של 6000 משימות דמה בעברית.
- ה-API `GET /api/tasks` מחזיר רק משימות לא סגורות.
- השאילתה משתמשת ב-`AsNoTracking`, השלכה ל-DTO, ואינדקס על `Status`.
- השרת מודד זמן שליפת נתונים באמצעות `Stopwatch`.
- הדפדפן מודד זמן בקשת API וזמן הצגת הטבלה.
- המסך והטקסטים למשתמש מוצגים בעברית.


## הרצה

```bash
dotnet restore
dotnet run
```

לאחר ההרצה יש לפתוח את הכתובת שמופיעה בטרמינל, בדרך כלל:

```text
http://localhost:5259
```

כתובת ה-API:

```text
http://localhost:5259/api/tasks
```

## הרצה ב-VS Code

פתחו את תיקיית הפרויקט ב-VS Code ולחצו `F5`. קבצי ההגדרה תחת `.vscode` יבנו ויפעילו את הפרויקט.

## בסיס הנתונים

קובץ SQLite נוצר בשם `tasks.db` בתיקיית הפרויקט. אם הקובץ לא מכיל 6000 משימות ומתוכן 4000 לא סגורות, מנגנון האתחול יוצר אותו מחדש אוטומטית בהרצה הבאה.

סקריפט מילוי הנתונים נמצא בקובץ:

```text
Data/DatabaseInitializer.cs
```
